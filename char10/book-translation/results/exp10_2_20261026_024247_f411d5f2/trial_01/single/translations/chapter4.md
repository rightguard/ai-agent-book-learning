# 第 4 章：微调与部署

通用模型很少能开箱即用地适配特定产品。通常的解决办法是**微调**：在更小、更针对特定任务的数据集上继续训练模型，使其适应你的领域，同时保持其通用能力。

微调改变了模型如何将**提示词**转化为答案，但并不会改变基本流程：文本变成**词元**，每个词元变成**嵌入向量**，**推理**产生结果。改变的是模型学习到的权重。

```python
def fine_tune(model, dataset):
    for prompt, target in dataset:
        loss = model.loss(prompt, target)   # compare output to target
        model.update(loss)                  # adjust weights
    return model
```

微调之后是**部署**：将模型封装在 API 之后，让真实用户能够发送提示词并获得答案。此时，之前提到的种种问题会全面回归。时延必须保持低位，吞吐量必须保持高位，而上一章中的 KV 缓存和批处理则承担了主要工作。

完整的旅程——词元、嵌入向量、提示词、推理、时延、微调和部署——至此已经走完。一个曾经只是研究产物的模型，如今已成为人们可以实际使用的服务。
